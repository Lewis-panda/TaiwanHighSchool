# 高一／高二數學、物理與化學學生講義

本專案收錄 48 份高一、高二數學、物理與化學學生講義。點選下方章節名稱，即可在瀏覽器開啟或下載 PDF。

每份講義包括概念說明、公式或方法的推導、例題、練習與解答；部分章節另有應用情境與模型限制。學生可用於自學，家長與教師也可依章節查閱內容。

> 使用前務必檢查內容與計算結果是否正確，並與現行課本、課綱及其他可靠資料來源交叉核對。

## PDF 與 LaTeX 檔案

- `pdf/` 放置 48 份最終 PDF，由 LaTeX 以 Tectonic 編譯。
- `latex/<講義代號>/<講義代號>.tex` 是對應的完整 LaTeX 製作檔。
- `latex/<講義代號>/assets/` 放置該份 LaTeX 實際引用的向量 PDF 圖。
