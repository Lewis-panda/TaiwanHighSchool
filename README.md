## 製作檔

實際來源放在 `content/`：正文是 Markdown，數學式以 LaTeX 語法撰寫；圖版是可重生 SVG。`_tools/` 保存繪圖程式，`styles/`、`templates/`、`tools/` 與 `publishing/` 保存 HTML → PDF 的完整製作與驗收管線。

本專案沒有用舊的純 `.tex` 檔產生這批 PDF，因此未保留無法對應成品的舊 `.tex`。目前提交的 110 個必要來源與管線檔，已在隔離目錄重建出與 `pdf/` 相同的成品。

```sh
npm install
npm run preflight -- --set review-2026-08-24
npm run release -- --set review-2026-08-24
npm run verify -- --set review-2026-08-24
```

完整測試在本機工作樹執行；公開版只保留產出這 8 份 PDF 所需的精確檔案閉包。本機參考教材、逐頁比對紀錄與研究資料不在公開版本中。
